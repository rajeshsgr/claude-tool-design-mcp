Claude · Agent Tool Design · MCP Integration

Order Status Agent: Four Examples

Four progressive demos: direct Python tool calling, MCP integration, multi-tool selection, and structured MCP execution errors.

Example 1: Claude selects a tool; app.py calls a local Python function. Example 2: Claude selects a tool; the MCP client calls the MCP server through the protocol. In both examples, the mock API runs in order_api.py.

Other test IDs: ORD-ABCD validation · ORD-1003 business · ORD-1004 permission · ORD-9999 valid empty result. Protocol errors are separate JSON-RPC errors, not isError:true tool results.

Note: With tool_choice=auto, Claude may answer without a tool (e.g., “Hello” or missing order ID). The diagrams illustrate typical successful tool calls; selections can vary. The second Claude call happens in the agent loop after the tool result is added to messages.
